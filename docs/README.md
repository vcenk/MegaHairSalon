## Strategic Positioning

Don't compete for "Vancouver hair salon" — own these instead:
- **Primary:** Coquitlam + Tri-Cities (Port Moody, Port Coquitlam)
- **Moat:** "Turkish hair salon Vancouver" (low competition, authentic story)
- **Service angle:** Master colourists, blonde/balayage specialists, 1984 heritage
