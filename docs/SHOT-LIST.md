## Technical specs (per `docs/01-design-system.md`)

- Format: **AVIF primary, WebP fallback, JPG last resort** — all delivered via `next/image`
- Hero: **2400×1600 source**, served at 1920w/1280w/640w
- Gallery: **1600×1200 source**
- All images: descriptive filename, `alt` text, explicit `width`/`height`
- Compression: **under 200KB per delivered image**, hero under 150KB
- Above-fold → `priority`; below-fold → `loading="lazy"` + `placeholder="blur"`
