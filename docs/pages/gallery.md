## Image SEO

This page is critical for image search rankings. Every image must:
- Have descriptive filename: `balayage-caramel-blonde-bulent-megas-coquitlam.jpg`
- Have detailed alt text (60–120 chars)
- Be included in `sitemap-images.xml`
- Be served via next/image in AVIF format
- Be < 200KB at served size
